Hallucination is a feature, not a bug
An LLM is a next-token sampler. Imagining plausible continuations is what it is for.

Sampled output

hasStatus: "probably shipped"

Not a real status

Allowed values: Paid · Shipped · Refunded. Nothing in the model knows that. It only knows what usually comes next.

✕
When an agent issues a duplicate refund it is not malfunctioning. It is generating the most probable next tokens.
A prompt can say "only use valid statuses". A sampler can still sample something else.
The fix is not a longer prompt. It is a layer outside the model that can say no.
